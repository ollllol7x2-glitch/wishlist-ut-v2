# 찜 기존안·개선안 비교 UT 프로토타입 v2

## 기준

- 사용성 테스트: `13_사용성테스트/찜_기존-개선안_사용성테스트_설계_v2_0901.md`
- 기능: `10_설계 스코프 및 IA 매핑/찜_UX개선_기능명세서_v2_0831.md`
- 화면: `12_와이어프레임/찜_와이어프레임_After_v25_0901.html`
- Hi-fi: `output/hifi/wishlist-v1/`

Hi-fi 원본은 변경하지 않는다. 이 폴더는 T1~T4 비교 UT를 위한 상호작용, 기존안 화면, 과업 기록 상태를 추가하는 전용 복사본이다.

## 현재 구현 범위

- 모바일 세션 홈: `facilitator.html`
- 참가자용 과업 시작·기록 화면: `index.html`
- 개선안 Hi-fi 복사본: `prototype.html`
- 공통 과업 정의: `task-manifest.js`
- 통합 저장·CSV: `session-store.js`

T1~T3의 기존 지그재그·개선안 비교 흐름과 개선안 전용 T4 복원 흐름을 완성했다. 기존 조건은 실제 지그재그 앱으로 전환하므로 시간은 자동 기록하고, 앱 내부 탭·스크롤 수는 진행자가 결과 화면에 입력한다. 개선안은 시간·탭·스크롤 제스처·경로·성공 시점을 자동 기록한다. T2는 다시 살펴볼 상품·찜 내 검색·직접 스크롤 경로를 허용하되 은색 로고가 있는 흰색 카드지갑의 상세를 확인했을 때만 자동 완료한다. T3는 찜 기본 화면에서 숨긴 상품을 거쳐 정리 제안을 직접 발견하며, 28개 정리를 실행하면 자동 완료한다. 결과 화면에서 정리 대상·숨김·30일 후 삭제·복원 이해를 함께 기록한다.

## 실행

모바일과 컴퓨터가 같은 네트워크에 있을 때 이 폴더를 로컬 서버로 열고 휴대폰에서 `facilitator.html`에 접속한다. `file://`로 직접 열면 브라우저별 저장·iframe 제한이 생길 수 있으므로 로컬 서버 사용을 권장한다.

T4는 정리 완료 바텀시트를 닫은 찜 기본 화면에서 시작해 숨긴 상품 진입점 발견, 대상 상품 선택, 원래 폴더 복원을 실행하며 대상 상품을 복원했을 때만 자동 완료한다.
